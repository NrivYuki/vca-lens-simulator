# DESIGN.md — 「無骨で必要十分」なサイトの設計方針

このファイルは、claude.ai のチャットで作ったデザインを Claude Code に引き継ぐためのメモです。
Claude Code はこのファイルを最初に読み、ここに書いた方針に従って HTML/CSS を作成・修正してください。

## 3. 設計原則

1. **情報が主役**：トップを開いた時点で「何が新しいか」が見えること。理念やビジョンの長文で画面を埋めない。
2. **角を立てる**：`border-radius` は使わない（0）。
3. **構造は線で示す**：影・グラデーション・すりガラス効果は使わない。区切りは1px罫線、見出し下の2px線、上端4pxの色帯で示す。
4. **色は1色だけ**：アクセントは `--accent` の1色。それ以外は墨・灰・白で構成する。
5. **文字は文字のまま**：見出し、ボタン、バナーを画像にしない。
6. **固定幅にしない**：最大幅1200pxの可変幅。スマホでは縦に積む。

## 4. デザイントークン

### 色
```css
:root {
  --accent:      #1F3A5F; /* 候補: #7A1F1F 臙脂 / #1F4D3A 深緑 / #1A1A1A 墨 */
  --ink:         #1A1A1A; /* 本文・見出し線 */
  --ink-2:       #3A3F44; /* 補足本文 */
  --muted:       #555B61; /* 日付・ラベル・注記 */
  --rule:        #C8CCD0; /* 枠線・主要罫線 */
  --rule-light:  #DDE0E3; /* 一覧の行区切り */
  --rule-faint:  #EEF0F1; /* カテゴリ内リスト区切り */
  --band:        #F2F3F4; /* 表ヘッダー・フッター背景 */
  --placeholder: #E4E7EA; /* 画像の仮置き */
  --bg:          #FFFFFF;
  --link-hover:  #0E1F36;
}
```
- 帯ナビの区切り線は `rgba(255,255,255,.25)`、現在地の項目は `rgba(0,0,0,.22)` を重ねて暗くする。
- すべての文字色は、背景に対して 4.5:1 以上のコントラストを確保している。

### 書体
- 本文：**Noto Sans JP**（400 / 500 / 700）
- 日付・版番号・英字の小見出し：**IBM Plex Mono**（400 / 500）

### 文字サイズ
| 用途 | サイズ |
|---|---|
| 本文 | 14px / 行間 1.7 |
| セクション見出し（h2） | 17px（折衷案は19px） |
| ロゴ文字 | 22px |
| 表・一覧 | 13px |
| 注記・補助ナビ | 12px |
| ラベル・英字小見出し | 11px |

### レイアウト
- コンテナ：`max-width: 1200px; margin: 0 auto; padding: 0 24px;`
- 2カラム：`display:flex; flex-wrap:wrap; gap:24px;`
  - メイン：`flex: 999 1 560px; min-width: 0;`
  - サイド：`flex: 1 1 260px;`（幅が足りなければ自動で下に回る）
- セクション同士の間隔は 32〜40px。

## 5. 部品

| 部品 | 仕様 |
|---|---|
| ヘッダー | 上端に `4px solid var(--accent)`、下端に `1px solid var(--rule)`。左にロゴと社名、右に縦線で区切った補助リンク |
| 帯ナビ | 背景は `var(--accent)`、白文字、項目間を縦線で区切る。現在地は暗くする。`flex-wrap` で折り返す |
| セクション見出し | `border-bottom: 2px solid var(--ink)`。右端に「一覧を見る ›」 |
| 番号付き見出し（折衷案） | 見出しの前に等幅フォントで「01」「02」…をアクセント色で置く |
| お知らせ一覧 | 1行ずつ「日付（等幅・灰）＋本文リンク」。行の区切りは `1px var(--rule-light)` |
| 表 | 外枠は `1px var(--rule)`、ヘッダー背景は `var(--band)`。`overflow-x:auto` の箱に入れ、`min-width: 600px` |
| ラベル | 3種類で区別する：枠線のみ・アクセント色／枠線のみ・墨／塗りつぶし。**色だけでなく形でも見分けられること** |
| サイドのリンク列 | 枠線付きのブロックを縦に並べ、`margin-bottom:-1px` で線を1本に重ねる。上に英字の小見出し（等幅）、下に日本語の名称、右端に「›」 |
| 行動ボタン | アクセント色で塗りつぶした角ばった帯に白文字 |
| フッター | 背景は `var(--band)`。縦線で区切ったリンク列と、コピーライト・登録番号 |

## 6. 使わないもの（「生成AIらしさ」の除去リスト）

既存のHTMLにある場合は、以下を取り除くか置き換える。

- 紫から青へのグラデーション、文字のグラデーション
- 大きな角丸のカード、カードの影、ホバー時に浮き上がる効果
- すりガラス（`backdrop-filter`）、ネオンのような光彩
- 絵文字アイコン、「✨」「🚀」付きの見出し
- 中身の薄い全画面ヒーロー（大きなキャッチコピーとボタン2つだけ、のような構成）
- 同じ形のアイコン付きカードが3つ並ぶだけの「特徴」セクション
- 決まり文句：「シームレスな」「次世代の」「革新的な」「〜を再定義」「あなたの〜を加速」
- 架空の数値（「10,000+ ユーザー」など）や架空の推薦文
- 左端だけに色線を引いたカード

**文言の方針**：事実（何を・いつ・どこで・いくらで）だけを書く。形容詞を削っても意味が通るなら削る。

## 7. 実装上の注意（追加情報）

- **スタイルの整理**：書き出したHTMLは、各要素の `style` 属性に直接スタイルを書いた形。複数ページに展開する際は、共通CSSファイルとクラスに切り出すこと（例：`.site-header`, `.nav-band`, `.sec-head`, `.news-list`, `.data-table`, `.tag--outline`, `.tag--solid`, `.side-links`, `.cta`）。§4のトークンは `:root` のCSS変数として定義する。
- **中国本土向けに公開する場合**：Google Fonts は中国本土からの読み込みが不安定、または遮断されることが多い。フォントは自前で配信（`@font-face`）するか、システムフォント（`"PingFang SC", "Microsoft YaHei", sans-serif` など）に切り替えること。
- **アクセシビリティ**：ナビには `aria-label`、装飾目的の「›」には `aria-hidden="true"` を付ける。リンクは `<a href>`、ボタンは `<button>` を使い、`div` にクリック処理を付けない。
- **画像**：メインビジュアルは仮置きの灰色の箱。実際の画像を入れる際は `width` と `height` を指定し、`object-fit: cover` を使う。
- **運用**：コピーライトの年や仮置きの連絡先を放置しないこと（nidek.it の反省点）。お知らせを更新し続けられる形にしておくことが、このデザインの前提。
- **非公開情報**：個人開発者版の作品情報は、公開してよい段階になるまで `[ ]` のまま残すこと。

## 8. Claude Code での進め方

1. このファイルと3つのHTMLを、リポジトリの `design-ref/` に置く。
2. リポジトリで Claude Code を起動し、次のように指示する。

```
design-ref/DESIGN.md を読み、design-ref/corporate.html を基準デザインとして、
このリポジトリのHTML/CSSを作り直して。
- §6 の要素はすべて除去し、§4 のトークンを :root に定義すること
- スタイルは共通CSSにまとめ、style 属性に直接書かないこと
- 文言は事実だけ残し、決まり文句は削ること。不明な事実は [ ] のプレースホルダーにすること
- まず変更方針と対象ファイルの一覧を見せてから着手すること
```

3. 作業はブランチを切って行い、変更前後をブラウザで見比べてから取り込む。

## 9. ツール画面の型（`tool-template.html`）

計算や形を確かめる道具の画面は、サイトのトップ（§2 の3案）とは別に、次の型でそろえる。VCA Lens Simulator と VCA Shape Maker がこの型でできている。参考にしたのは、2010 年代の住宅設備メーカーの「製品カタログをウェブ上でシミュレーション」する画面（左に設定、右に 3D、下に参考価格と出力のボタン）。

| 場所 | 中身 | 仕様 |
|---|---|---|
| 上の帯 | 左にツール名、右に「いま表示している条件」を／で区切って1行で | 背景は濃い灰 `--bar`、名前の部分は一段濃い `--bar-2`。名前の幅は左の設定と同じ（`--side-w`） |
| 左の設定 | 項目をタブで切り替える。1 タブ 1 まとまり（読み込み・入力・結果・書き出しなど） | タブは灰の地に 1px の枠、選んだタブだけ白地・上端に 3px のアクセント線で下の面とつながる。`role="tablist"`・`aria-selected`、左右の矢印キーでも切り替え |
| 右のツールバー | 表示の切り替え・視点・表示する項目 | 背景は `--band`、区切りは縦の 1px 線 |
| 表示の面 | 3D・図面・画像 | 3D を置く面だけ、上が薄い空色・下が白のグラデーション（`.view.sky`）。§6 のグラデーション禁止の例外で、これ以外には使わない |
| 下の帯 | 左に主な結果（参考価格の位置）、右に書き出しのボタン | 結果の数値は等幅。ボタンは線画の絵の下に短い名前を置き、縦の 1px 線で区切る。文字だけ・絵だけにしない |

- 左のタブに置くのは、いつも見たいもの（入力・結果の表・書き出す中身）。何度も押すボタン（保存・印刷）は下の帯に出す。
- 知らせ（注意・エラー）は、どのタブを開いていても見える位置に置く。
- タブで隠れた面の中に canvas などの大きさを測るものがあるときは、タブを開いたときに描き直す。
- 狭い画面では、表示の面を上・設定を下に積み、下の帯のボタンは横幅いっぱいに並べる。
- ダークモードは同じトークンの暗い版で持つ（`tool-template.html` の `@media (prefers-color-scheme: dark)`）。
