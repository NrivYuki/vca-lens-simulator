# 計算の確かめ

厚みの計算が、公開されている資料の値とどのくらい合うかを確かめた結果です。どれも `tests/lens.test.js` に回帰テストとして入れています。

| 確かめたこと | 資料 | 結果 |
|---|---|---|
| 面のサグと縁厚の幾何（球面） | ZEISS Single Vision Fact Sheets（2023）、synchrony Semi-Finished SV Spherical 1.59、直径 74 mm の 5 種類のブランク（前面の曲率半径・後面カーブ・中心厚・縁厚） | 差は 0.02〜0.22 mm（5 種類のうち 3 種類は 0.03 mm 以内） |
| 同上（非球面） | 同資料、synchrony Semi-Finished SV AS 1.67、直径 73 mm | 差は最大 0.46 mm。前面が非球面のためで、このツールの対象外（参考） |
| 平凹レンズの縁の増分 | Laramy-K「Methods for Estimating Lens Thickness」の K 値の表（Hard Resin、直径 40〜80 mm） | 表は近似式（半径² × D / 2000(n − 1)）の値で、このツールの正確なサグとは 3% 以内 |
| 乱視・偏心のあるレンズ | 同資料の計算例：−3.00 −1.00 × 45、ED 54 mm、偏心 3 mm、n = 1.537、中心厚 1.0 mm → 耳側の縁 約 3.91 mm（実際のレンズとの差は 0.15 mm 以内とされる） | このツールは 4.12 mm（ベースカーブ 3 D）。差 0.21 mm。資料のレンズは非球面で、計算例は薄いレンズの近似 |
| 球面のマイナスレンズ | 厚いレンズの式で求めた縁厚 | 一致（1e-6 mm） |
| プラスレンズの中心厚 | 近似式（半径² × D / 2000(n − 1)＋最小縁厚） | 0.1 mm 以内 |

## わかったこと

- 球面・トーリックの面であれば、このツールの縁厚はメーカーの公表値と 0.2 mm 程度で合います。JIS T 7337 の厚さの許容差（±0.3 mm）より小さい差です。
- 非球面のレンズでは 0.5 mm 近くずれることがあります。非球面の設計値はメーカーが公開していないため、このツールでは扱えません。
- 実際の仕上がりは、ブランクの選び方（ベースカーブ）、加工機の設定、ヤゲンの位置の決め方でも変わります。
