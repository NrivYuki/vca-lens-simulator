# 眼鏡づくりの基礎知識

眼鏡ができるまでの流れと、そこで使う言葉・数値をまとめます。VCA Lens Simulator・VCA Shape Maker がどの工程を扱っているかは、最後の「このツールとの対応」に書きます。

> 出典は末尾にまとめています。出典で確かめられなかった一般的な知識には **（一般）** と付けています。数値はメーカー・資料によって違うことがあるので、正確な値は各社の技術資料で確かめてください。

## 1. 全体の流れ

```
 視力の測定 ─→ 処方 ─→ フレーム選び・装用の測定 ─→ レンズの手配
                                                    │
         ┌──────────────────────────────────────────┘
         ▼
 玉形の測定（トレーサー）─→ 芯取り・ブロック ─→ 縁の加工（玉摺り）─→ 面取り・穴あけ
         ─→ 枠入れ ─→ 検査 ─→ フィッティング・お渡し
```

| 誰が | 何をするか |
|---|---|
| 眼科・眼鏡店 | 視力を測り、度数を決める（処方） |
| 眼鏡店 | フレームを選び、瞳の位置などを測る。レンズを手配し、フレームの形に削って入れ、顔に合わせて調整する |
| レンズメーカー | レンズの素材を作り、度数の面を削って磨き、膜を付ける |
| フレームメーカー | 部品を作って組み立て、表面を仕上げる。日本では福井県鯖江市が国内生産の約 9 割を占める |

日本では 2022 年 4 月に、技能検定の職種として「眼鏡作製職種」（眼鏡作製技能士）ができました。視力の測定、レンズの加工、フレームのフィッティングなどを担う職種で、試験は日本眼鏡技術者協会が行います。

## 2. 処方（度数）の読み方

| 記号 | 意味 | 値の例 |
|---|---|---|
| R / L（OD / OS） | 右眼 / 左眼 | |
| S（SPH） | 球面度数。近視はマイナス、遠視はプラス **（一般）** | −2.50 D |
| C（CYL） | 円柱度数（乱視の強さ）。乱視が無ければ書かない | −0.75 D |
| AX（Axis） | 乱視の軸の向き。1〜180° | 180 |
| ADD | 加入度数。老視（老眼）の分を近くを見る部分に足す | +2.00 D |
| P / Base | プリズムの量と向き。眼の位置のずれ（斜位など）を補う | 1.0Δ BI |
| PD | 瞳孔間距離。レンズの光学中心を瞳の前に置くために使う。片眼ずつ測った値を単眼 PD という | 63 mm（31.5 / 31.5） |

- 単位の D（ディオプター）は、焦点距離（m）の逆数です **（一般）**。
- 屈折異常は、近視・遠視・乱視が S と C で、老視が ADD で表されます **（一般）**。
- 角度は、検者が装用者を正面から見て 3 時の方向を 0° とし、反時計回りに数えます（ISO 8429。いわゆる TABO 表示）。

## 3. フレーム

### 各部の名前

| 名前 | 場所と役割 |
|---|---|
| リム | レンズを囲む縁 |
| ブリッジ | 左右のリムをつなぐ部分 |
| 智（ヨロイ） | リムと丁番をつなぐ部分。ロゴが入ることが多い |
| 丁番（ヒンジ） | テンプルを開け閉めする部分 |
| テンプル（つる） | 耳にかける部分。先端の樹脂のカバーをモダン（先セル）という **（一般）** |
| 鼻パッド（鼻あて） | 鼻の両脇に当てて支える。メタルでは交換できる部品、セルではリムと一体のことが多い |

### リムの種類

| 種類 | 形 | レンズの縁の加工 |
|---|---|---|
| フルリム | レンズ全体をリムで囲む | 縁に山形のヤゲンを付けて、リムの内側の溝にはめる |
| ハーフリム（ナイロール） | 上側だけリム、下はナイロンの糸で留める | 縁に細い溝を掘って、糸を掛ける |
| リムレス（ツーポイント） | リムが無く、レンズに穴を開けて金具で留める | 縁は平らに仕上げ、穴を開ける |

### 寸法の表し方

テンプルの内側などに「52□18-145」のように書かれています **（一般）**。

| 数値 | 意味 |
|---|---|
| 52 | 玉形幅 a（レンズの横幅） |
| □ | ボクシング方式（レンズを長方形の箱で囲んで測る）で測ったという印 |
| 18 | レンズ間距離 d（DBL。ブリッジの幅にあたる） |
| 145 | テンプルの長さ |

ボクシング方式・玉形中心・玉形幅・玉形高さ・レンズ間距離などの言葉は JIS B 7281（ISO 8624）で決まっています。

### 素材と作り方

| 種類 | 主な素材 | 作り方 |
|---|---|---|
| メタル | チタン（純チタン・βチタン）、ステンレス、洋白、モネル **（一般）** | 線材や板をプレスし、部品をロウ付け・溶接でつなぎ、バレル研磨で磨き、メッキや塗装で仕上げる。チタンは部品ごとに性質の違う材を使い分ける |
| セル（プラスチック） | アセテート、セルロイド **（一般）** | 板状の生地からフロントやテンプルを削り出し、何段階も磨いて艶を出す。アセテートは加工の難しい素材とされる |

鯖江では、工程ごとに専門の職人・工場が分かれて受け持つ分業で作られてきました。

## 4. レンズ

### 素材

| 屈折率 | 主な素材 | アッベ数 | 比重 | 特徴 |
|---|---|---|---|---|
| 1.50 | CR-39 **（一般）** | 約 58 **（一般）** | 約 1.32 **（一般）** | 色のにじみが少ないが、度が強いと厚くなる |
| 1.59 | ポリカーボネート **（一般）** | 約 30 **（一般）** | 約 1.20 **（一般）** | 割れにくい。子ども用・保護用に使う |
| 1.60 | MR-8 など | 36〜41（資料により違う） | 約 1.30 **（一般）** | 薄さと色のにじみの少なさの釣り合いがよく、標準的に使われる |
| 1.67 | MR-7 など | 約 32 | 約 1.35 | 薄く軽い |
| 1.74 | | 約 33 | 約 1.46 | いちばん薄い |

- **屈折率** が高いほど、同じ度数でもレンズを薄くできます。
- **アッベ数** は色のにじみにくさです。大きいほど、レンズの周辺で色がにじみにくくなります。
- **比重** が小さいほど、同じ体積なら軽くなります。

### 設計

| 区分 | 種類 |
|---|---|
| 面の形 | 球面、非球面（外面）、両面非球面。非球面にすると、同じ度数でも厚みやコバ（縁）の厚さを抑え、周辺のゆがみを減らせる |
| 焦点の数 | 単焦点、多焦点（二重焦点など）、累進屈折力レンズ |
| 累進の種類 | 遠近、中近、近々 **（一般）**。遠くを見る部分から近くを見る部分へ度数が連続して変わる。度数が変わる区間の長さ（累進帯長）はおおむね 9〜18 mm、加入度数は +0.50〜+4.00 D ほど |

### 表面の膜 **（一般）**

ハードコート（傷を防ぐ）、反射防止膜（マルチコート）、撥水膜、紫外線カット、ブルーライトカット、調光（紫外線で色が濃くなる）などがあります。

### レンズの作り方

1. **素材を固める（注型重合）**：2 枚の型（モールド）を決まった間隔で向かい合わせ、周りをテープなどで巻いて閉じ、液状のモノマーを流し込んで固めます。
2. **完成品とセミ品**：よく使う度数は、両面とも仕上がった **フィニッシュトレンズ**（在庫レンズ）として作ります。それ以外は、外面だけを仕上げた **セミフィニッシュトレンズ**（ブランク）を作っておきます。
3. **度数の面を削る（サーフェシング）**：注文ごとに、外面のカーブ（ベースカーブ）でブランクを選びます。その後、次の手順で内面を仕上げます。
   - ブロッキング：外面をテープで守り、機械に取り付けるための台（ブロック）を付ける
   - 切削：ジェネレーターで内面を削り、処方の度数のカーブにする。フリーフォームの機械は、荒削りのあとダイヤモンドの刃で細かく削る
   - スムージング：削った面をなめらかにする
   - 研磨：柔らかい研磨具で磨いて透明にする。フリーフォームの複雑な面は、面に沿って変形する研磨具ができたことで作れるようになった
4. **膜を付ける**：ハードコート、反射防止膜などを付けます。プラズマで傷防止の層を付ける製造ラインもあります。
5. **検査**：度数・軸・外観を確かめます。

## 5. 眼鏡店での加工（玉摺り）

| 工程 | すること |
|---|---|
| 玉形の測定 | トレーサーで、フレームのリムの内側の溝をなぞって形を測る。今の機械は、両眼の形・溝の傾き・ヤゲンの形まで測る。測った形のデータを「玉形」という |
| 芯取り（マーキング） | レンズメーターで光学中心と乱視軸に印を付け、光学中心が瞳の前（PD・アイポイントの高さ）に来るように、玉形との位置関係を決める |
| ブロック | 決めた位置に、レンズを機械に固定するための吸着具を付ける。この位置が加工の基準になる |
| 縁の加工 | エッジャー（玉摺り機）で、玉形どおりにレンズの縁を削る。フルリムはヤゲン、ハーフリムは溝、リムレスは平らに仕上げる。ヤゲンの山を前面と後面のどこに置くかは、機械が自動で決めるか、人が指定する |
| 面取り | 削った縁の角は鋭く、手を切ることがあるので、小さく面を取る（安全面取り・糸面） |
| 穴あけ | リムレスでは、金具を留める穴や切り欠きを開ける |
| 枠入れ | メタルはリムのネジをゆるめてはめる。セルは枠を温めて広げてはめる **（一般）** |
| 検査 | 度数・軸・光学中心の位置・左右のプリズムの差が許容差に入っているかを確かめる（JIS T 7337） |
| フィッティング | 顔に合わせてテンプル・鼻パッドを曲げ、ずれないように調整する |

ひとつの加工にかかる時間は、簡単なもので 3 分ほど、高屈折率で穴あけのある複雑なもので 7 分ほどという例があります。

## 6. 掛けたときの位置（装用のパラメータ）

| 言葉 | 意味と目安 |
|---|---|
| 頂点間距離 | 角膜の頂点からレンズの裏面までの距離。日本人は 12 mm ほど、欧米人は 13.75 mm ほどが標準とされる |
| 前傾角（パント） | 正面から見たレンズの上端が手前に傾く角度 |
| そり角（フェイスフォーム） | 上から見て、レンズが顔に沿って曲がる角度 |
| アイポイント | 瞳の正面にあたるレンズ上の位置。累進レンズでは、遠くを見る部分の基準になる |

- 頂点間距離が変わると、効く度数が変わります。度数 D のレンズで距離が ΔL（m）だけ変わると、効き方は ΔD = D² × ΔL だけ変わります。たとえば −10.00 D では、検眼枠の前の列と後ろの列で約 1.50 D の差が出ます。
- 前傾角やそり角が付くと、乱視の無い人でも、斜めに見るぶん乱視があるように効くことがあります。

## 7. このツールとの対応

| 工程 | ツール | 扱っていること |
|---|---|---|
| 玉形の測定 | VCA Shape Maker | トレーサーの代わりに、写真や商品画像から玉形を作り、VCA（トレーサーと加工機の間でやり取りする形式）にする |
| 芯取り・縁の加工 | VCA Lens Simulator | 玉形と処方・PD・アイポイントの高さから、加工後のレンズの厚み・コバ・ヤゲンの位置を計算して、3D と三面図で見せる |
| 検査 | VCA Lens Simulator | JIS T 7337 の許容差を出す |
| レンズの設計 | 対象外 | 非球面・累進の面は扱わない（前面は球面、後面は球面・トーリックとして計算） |

関連する規格の扱いは [standards.md](standards.md) にまとめています。
