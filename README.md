# VCA Lens Simulator

VCA（OMA / DCS）の玉形と処方から、加工後のレンズの厚み・コバ（縁の厚み）・ヤゲンの位置を計算します。結果は、マウスで回せる 3D と三面図（第三角法）で確かめられます。

[vca-guide](https://github.com/NrivYuki/vca-guide)（VCA通信の解説と vca-parser）と [vca-ptn-converter](https://github.com/NrivYuki/vca-ptn-converter)（玉形の変換）の続きとして作っています。

> 計算は前面を球面、後面を球面・トーリックとした近似です。値は目安で、実際の加工結果とは照合していません。

## 使い方

`index.html` をブラウザで開きます。サーバーは要りません。3D 表示に使う three.js を CDN から読み込むので、インターネットへの接続が必要です。

設定は画面の左にあり、タブ（玉形・処方・加工・結果・許容差・VCA）で切り替えます。上の帯にはいま表示している条件、下の帯には中心厚・最厚と最薄の縁と、書き出しのボタンが出ます。

1. 「玉形」のタブで、VCA ファイル（.vca / .oma / 中身が VCA の .job・.ptn）を置くか、サンプルを選びます。
2. 「処方」のタブで、処方（SPH・CYL・AX・プリズム）、単眼の心取り距離（片眼 PD）、心取り点の高さ（OCHT）、レンズ間距離（DBL）を入れます。VCA にこれらのレコードがあれば自動で入ります。
3. 「加工」のタブで、素材、最小中心厚・最小縁厚、縁の加工（ヤゲン・溝掘り・平）を選びます。

ファイルはブラウザの中だけで処理し、どこにも送信しません。

## 計算のしかた

座標は、検者が装用者を正面から見た向き（x 右、y 上、z 手前）で、原点は玉形中心（ボクシング方式の外接長方形の中心）です。角度は 0° が 3 時方向、反時計回り（VCA の玉形と同じ）。

1. **光学中心の位置**：水平は鼻側へ `(玉形幅 a + レンズ間距離 d) / 2 − 単眼の心取り距離`、垂直は `OCHT − 玉形高さ b / 2` ずらします。
2. **前面**：ベースカーブ（TIND 1.53 基準の D）から曲率を決めた球面です。空欄なら等価球面度数から Vogel の式で決めます（プラスは SE + 6、マイナスは SE / 2 + 6）。
3. **後面**：後頂点屈折力が処方に合うように、乱視軸の向きと直交する向きの曲率を決めた双円錐面（トーリック）です。前面の屈折力は中心厚で補正します（厚いレンズの式）。
4. **プリズム**：くさび角 `Δ / 100 / (n − 1)` の分だけ、基底の向きに厚みを足します。
5. **中心厚**：最小中心厚と、「いちばん薄いところが最小縁厚になる厚み」の大きいほうです。中心厚と後面の曲率は互いに依存するので、数回繰り返して決めます。
6. **縁**：角度ごとに、前面と後面の高さの差をコバ厚とします。ヤゲンは山の高さと角度（既定 120°）から幅を決め、DCS の BEVP の決め方（前面に沿う・前面からの割合・フレームカーブ・中央・後面に沿う）で置きます。コバがヤゲンより薄いところでは山を細くします。

## 再現できないこと

- 非球面・両面非球面・累進（フリーフォーム）の面。メーカーの面の設計は公開されていません。
- メーカーごとのベースカーブの選び方、加工機ごとのヤゲン位置の決め方（フレームカーブに沿わせる方法など）。

## テスト

```sh
node --test tests/lens.test.js
```

球面レンズの縁厚を式と比べる、プラスレンズの中心厚、乱視・偏心・プリズムの向き、網が閉じていて体積が合うこと、サンプルの読み込みを確かめます。

画面は、Chrome をヘッドレスで動かして確かめます（Node.js 22 以上、インターネット接続が必要）。リポジトリのフォルダで実行し、画像は OS の一時フォルダの vca-ui-check に置きます。

```sh
node tests/ui/cdp.js index.html tests/ui/steps.js
```

確かめている項目は [docs/test-items.md](docs/test-items.md) にまとめています。
